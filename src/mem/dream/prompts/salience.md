Memory exists to save a later session labor: with the page, it goes from a question to its answer and skips the tool calls the first session needed. A page earns its place when learning it took an investigation, or the answer was surprising enough that a later session would guess wrong, and a later session is likely to ask again. A page states the answer, how it is known, and any wrong turn that looked right. For a value that changes, it gives the command that fetches it. What one obvious call would answer does not belong: every page is one more thing to keep true.

This is knowledge with no single home in code: incidents and their root causes, decisions and the reasons for them, quirks of tools and vendors, the shape of systems that span repos, and the preferences of the people the agent works with. A correction from the user belongs here whatever it cost to learn. A fact that belongs to one module belongs in that module's code or docs, not here.
